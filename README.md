# Cis Tier Logo

Скрипт на Python для автоматической генерации стильных карточек с результатами тиртестов игроков Minecraft. 

## Описание настроек кода

Для того чтобы настроить карточку под свои нужды или изменить данные игрока, открой файл `main.py` и измени значения переменных в самом начале скрипта. Все файлы ресурсов должны лежать в одной папке со скриптом:

```python
# Названия файлов ресурсов (должны быть в той же папке, что и main.py)
SKIN_PATH = "скин"                                 # PNG-скин игрока (взять с циса)
SWORD_ICON_PATH = "Diamond_Sword_JE3_BE3.png"      # Иконка алмазного меча
TESTER_AVATAR_PATH = "tirtester.png"               # Аватарка (голова) тиртестера
FONT_PATH = "arialmt.ttf"                          # Файл шрифта (рекомендуется Montserrat-Bold.ttf)
OUTPUT_PATH = "reqwai_result.png"                  # Имя готового файла карточки

# Текстовая информация на карточке
PLAYER_NAME = "ник"                                # Никнейм тестируемого игрока
TIER_RESULT = "High Tier 1"                        # Текущий полученный тир
PREV_TIER = "Low Tier 4"                           # Предыдущий тир игрока
TESTER_NAME = "Sahakyan"                           # Никнейм тиртестера
DATE_TEXT = "19 мая 2026 г."                       # Дата прохождения теста
